# Scene Plan Director — Mental Étudiant OpenMontage

Create exactly 12 retrieval slots for the long-form script. Every slot describes
observable real motion footage, maps to a script section, and includes 2–3
concise search queries plus `preferred_sources: [archive_org, wikimedia]`. Plan
2–3 distinct real video clips per scene. No still photos, AI images, generated
video, title-card-only scenes, or outside sources may fill a visual slot.

Use the requested motifs where relevant: student studying in a library, a person
alone in a dim room, writing or organizing notes, and a university campus in
rain. Keep query language concrete so archive search can retrieve actual footage.
Long-form slot holds must sum to 480 seconds. For demo mode retain only the
slots needed for a 60-second timeline and label the scope. Validate the scene
plan schema before checkpointing.
